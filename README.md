# Campus Voice — The Campus Bulletin

**One campus. One voice.**

Campus Voice is a web-based campus announcement platform designed to help students stay informed about important college updates in one convenient place. The platform brings academic announcements, college events, placement opportunities, and other campus notices together in a simple, interactive, and user-friendly interface.

The project is developed using **HTML, CSS, JavaScript, and Tailwind CSS**. HTML provides the structure of the application, CSS and Tailwind CSS handle styling and responsive layouts, and JavaScript adds interactivity and functionality.

### Key Features

- **Announcement Feed:** Displays campus announcements in organized cards with titles, descriptions, categories, and dates.
- **Category Filtering:** Allows students to filter announcements by Academic, Events, Placement, or All categories.
- **Search Functionality:** Helps users find relevant announcements quickly using keywords.
- **Like System:** Enables users to like announcements and view their popularity through like counts.
- **Bookmarks:** Allows students to save important announcements for future reference.
- **Trending Announcements:** Highlights popular posts based on engagement, helping students discover frequently liked announcements.
- **Add New Announcement:** Provides an option to create and publish new campus notices through an interactive form.
- **Dark Mode:** Offers a dark theme for a comfortable viewing experience in low-light environments.
- **LocalStorage:** Stores announcements and relevant user interactions in the browser so that supported data remains available after refreshing the page.
- **Expiry Tracking:** Helps identify expired announcements so students can distinguish outdated information from current notices.

### Technologies Used

- HTML5 — Structures the webpage using meaningful and semantic elements.
- CSS3 — Controls the visual design, layout, and responsive styling.
- JavaScript — Implements search, filtering, likes, bookmarks, trending posts, and theme switching.
- Tailwind CSS — Provides utility classes for efficient styling and layout development.
- Browser LocalStorage — Maintains supported application data across page refreshes.

### Project Objective

The main objective of Campus Voice is to make campus communication more organized, accessible, and engaging. Instead of searching through multiple messages or scattered notices, students can use a single platform to discover important updates and save information they may need later.

This project demonstrates practical frontend development skills, DOM manipulation, event handling, array operations, browser storage, and interactive user interface design. It also provides an opportunity to understand how individual web technologies work together to create a functional application.

Campus Voice is a student-focused project that aims to improve how campus information is presented, discovered, and managed through a clean and accessible digital experience.
